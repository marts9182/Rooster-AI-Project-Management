# Anna Sen Mennä — KDP Production Design (cover + publishable kit)

*Spec for taking the finished second-draft novel to fully KDP-ready. Produced 2026-06-01. Pairs with the revision spec/plan (same date) and `SESSION_STATUS.md`.*

## Goal
Produce everything needed to publish *Anna Sen Mennä* (pen name **Seven Martin**) on KDP as **ebook + paperback**: a high-quality cover, a print-ready interior, front/back matter, and a metadata kit.

## Locked decisions
| Decision | Value |
|---|---|
| Formats | Ebook **and** paperback |
| Trim size | **5.5″ × 8.5″** (US trade paperback) |
| Cover art | Generated by **Nano Banana Pro** (`gemini-3-pro-image-preview`), art only (no baked text) |
| Cover concept | **The sauna over the frozen lake** (winter dusk; dark rantasauna on pilings over cracked ice; black pines; bone-white snow; one ember-red sauna-window glow; desaturated deep-blue/charcoal; literary, restrained, *quietly wrong*) |
| Typography | **Composited** over the art with real fonts (serif: Playfair Display / Cormorant) — guarantees correct "Anna Sen Mennä" (the *ä*) + "Seven Martin" |
| Title / subtitle / byline | **Anna Sen Mennä** / *A Folk Horror Novel* / **Seven Martin** |
| Front matter | Title page + copyright page only (NO dedication/epigraph) |
| Back matter | "About Seven Martin" author page |
| Interior format | Print-ready **PDF via ReportLab**, 5.5×8.5, mirrored margins, running heads, page numbers, chapter openers |
| KU / KDP Select | Yes (ebook); free KDP ISBN |

## Deliverables
All under `projects/kdp-puzzle-press/first_book/files/`:
1. `cover/` — Nano Banana art candidates (PNG), the chosen art, the **ebook front** (`anna_sen_menna_cover_ebook.png`, 1600×2560 RGB), and the **paperback wrap** (`anna_sen_menna_cover_wrap.pdf`, front+spine+back, 300 DPI, 0.125″ bleed, spine from final page count).
2. `anna_sen_menna_kdp_print_interior.pdf` — print interior incl. front/back matter (yields page count).
3. `KDP_METADATA.md` — description/blurb, 7 keywords, 2 BISAC + KDP categories, pricing (ebook + paperback), title/subtitle/series fields, author bio, KU note.
4. `KDP_UPLOAD_CHECKLIST.md` — step-by-step upload guide + final QA.

## Cover composition spec
- **Ebook front:** 1600×2560 (10:16). Title block upper third; byline lower; subtitle under title. High contrast for thumbnail legibility.
- **Print wrap:** width = 2×(5.5+0.125) + spine; height = 8.5 + 2×0.125. Spine width = pages × 0.0025″ (white 60# stock) — computed after interior page count is final. Front panel = same art/type as ebook; spine = title + author + small imprint mark; back = blurb + (optional) short review space + barcode placeholder (KDP adds the barcode) + imprint line.
- Art generated at 3:4 / 2K then cropped/extended to the exact ratios with `sharp`.

## Mechanism
- Nano Banana via existing `web.ui/backend/ImageGenerationService.js` (active `GEMINI_API_KEY` in `web.ui/backend/.env.local`); a small new script drives it for this title (does not touch the puzzle-book registry).
- Compositing: `sharp` (Node) for raster (ebook front + wrap panels); ReportLab (Python) for the print interior PDF and, if cleaner, the wrap PDF.

## Sequence
1. Generate 2–3 sauna-concept art candidates → author picks/iterates.
2. Compose ebook front (chosen art + type).
3. Format print interior PDF (+ front/back matter) → final page count.
4. Compute spine → build paperback wrap PDF (front reuses the chosen art/type).
5. Draft metadata kit + author bio + back-cover blurb.
6. Final QA + upload checklist.

## Out of scope
- A+ Content graphics, paid ads, series page beyond a sequel hook line. (The book ends on a sequel hook; series setup is a later task.)
- The sensitivity-reader pass (separate, already briefed) — recommended before publishing but not blocking file production.
